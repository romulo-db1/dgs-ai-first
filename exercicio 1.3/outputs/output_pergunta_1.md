## Pergunta do Atendente

Qual o prazo de devolução para carga perigosa?

---

## Resposta

**[Resposta direta]**

Carga perigosa NÃO é elegível para devolução pelo processo padrão. O atendente deve orientar o cliente a contatar o setor de Gestão de Riscos pelo ramal 4500 para tratamento individual.

**[Fundamento]**

Conforme POL-001-3.2, as cargas perigosas classificadas nas classes 1 a 6 da ANTT "NÃO são elegíveis para devolução pelo processo padrão", abrangendo explosivos, gases, líquidos inflamáveis, sólidos inflamáveis, oxidantes e peróxidos, substâncias tóxicas e infectantes. O mesmo chunk determina que, para essa categoria, "o cliente deve entrar em contato com o setor de Gestão de Riscos (ramal 4500) para tratamento individual."

**[Observações]**

Existem duas versões do PROC-042 no contexto. Apliquei a v2 (mais recente). Se o contrato do cliente é anterior a 12/2023, valide com o Comercial.

Adicionalmente, os chunks disponíveis não estabelecem prazo específico para acionamento do ramal 4500 no caso de carga perigosa — diferentemente de carga danificada, que tem prazo de 48h (FAQ-Atendimento, Item 38, fonte informal). Caso o cliente questione sobre limite de tempo para acionar a Gestão de Riscos, recomenda-se escalar para o supervisor, pois essa informação não consta na documentação disponível.
